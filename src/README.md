# src/ — everything that isn't config

All application code lives here, split into three families:

| Folder | What lives there |
| ------ | ---------------- |
| [`app/`](./app/) | **Routes.** Every page the browser sees, plus Server Actions (`actions/`) and the REST API (`api/`). |
| [`components/`](./components/) | **React components.** Broken into `public/` (storefront), `admin/` (console), and `ui/` (small reusable primitives). |
| [`lib/`](./lib/) | **Everything non-visual.** Services, validation, auth, uploads, formatting, API helpers. |
| `generated/` | Prisma's typed client — generated by `npm run db:generate`, git-ignored. |

**The one rule that keeps this codebase sane:** pages and routes must stay thin.
Logic lives in `lib/services`, validation in `lib/validation`, and a page just
gathers data, hands it to components, and renders.
